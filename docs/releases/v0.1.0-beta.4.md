# Unpin v0.1.0-beta.4

This beta adds reusable inventory groups to Unpin, allowing an explicit
selection of supported skills, MCP servers, plugins, hooks, agents, and settings
to be managed as one named target.

## Highlights

- Personal and repository groups with explicit mixed-type inventory members.
- Group revision history, rename, delete, restore, and workspace isolation.
- CLI and TUI workflows for inspecting, planning, and toggling a whole group.
- MCP list, get, and plan tools with an opt-in, externally approved apply flow.
- File and standard-input transport for large approval challenges.
- Cohort backups, one-use approvals, authenticated operation evidence, and
  recovery-aware group status.

## Compatibility

This pre-1.0 beta adds inventory-group apply state to the public `unpin-core`
MCP context and transition-kind contracts. Beta consumers must recompile
against this release. Persisted group plans and definition history use the new
group schema versions rather than accepting earlier prototypes.

## Install

Download the archive for your platform:

- `aarch64-apple-darwin` for Apple Silicon macOS;
- `x86_64-apple-darwin` for Intel macOS;
- `x86_64-unknown-linux-gnu` for 64-bit GNU/Linux.

Extract the archive and place `unpin` on your `PATH`. Verify downloads against
`SHA256SUMS`. With GitHub CLI installed, verify build provenance:

```bash
gh attestation verify unpin-v0.1.0-beta.4-TARGET.tar.gz \
  --repo IgorArkhipov/unpin
```

## Safety

Start with read-only commands:

```bash
unpin providers
unpin doctor
unpin list --json
unpin group list
```

Persistent writes remain plan-first and require purpose-separated keychain
state, explicit confirmation, and the exact reviewed plan fingerprint. MCP
servers remain unable to approve their own group applies.

## Beta limitations

- Windows is not supported.
- Strict live gateway attachment, native MCP-reference lifecycle, and native
  managed-hook activation remain unavailable where enforcement cannot be
  proven.
- Publication is gated on attached provider-matrix evidence for the live-host
  and fixture coverage used for this release.
