# Unpin v0.1.0-beta.12

`v0.1.0-beta.12` makes the terminal command footer easier to scan and keeps
its visual mnemonics executable.

## Highlights

- Shows actions as named, underlined mnemonics instead of a key plus a repeated
  label.
- Displays the active view's controls, including named-group reach, scope,
  create, edit, rename, delete, history, restore, approval, save, and export.
- Fails fully non-interactive live approval requests before touching macOS
  Keychain; provider policy remains unchanged.
- Refreshes `http`, `jsonc-parser`, and `rmcp` to their current compatible
  direct releases.

## Verification

- Required CI, locked metadata, the full provider matrix, and live-host
  validation must pass on the tagged commit.
- The release workflow verifies the GNU/Linux artifact's `GLIBC_2.35`-or-older
  symbol ceiling and runs `--version` and `--help` in Debian 12.
- Each archive has GitHub build provenance, a CycloneDX SBOM, and a
  workflow-generated `SHA256SUMS` trust root. Verify a downloaded archive with:

```sh
shasum -a 256 -c SHA256SUMS
gh attestation verify unpin-v0.1.0-beta.12-x86_64-unknown-linux-gnu.tar.gz \
  --repo IgorArkhipov/unpin \
  --source-ref refs/tags/v0.1.0-beta.12 \
  --signer-workflow IgorArkhipov/unpin/.github/workflows/release.yml
```
