# Unpin v1.6.0

`v1.6.0` makes configuration changes easier to review in the terminal and
native macOS workbenches. TUI evidence wraps and scrolls, pane focus is explicit,
and long transcript trimming preserves screen state. Confirmation and apply
are paused when diagnostic panes or compact layouts hide the review. Planning
reveals evidence before a separate confirmation; review includes the entire
staged batch, including filtered-out items.

Native filter captions align with their controls. Inventory-group tables use
consistent rounded headers and bodies, and loading and blocked states no longer
look successful. Native interaction tests use supported XCUITest APIs and a
dedicated fixture app rather than private view introspection.

Compatible Cargo dependencies and pinned CI actions were refreshed using a
48-hour release-age minimum. The Aikido firewall remained enabled. Rust 1.98.0
and all release targets are unchanged. README and project guidance were edited
for clarity.

Authentication, approvals, locks, drift checks, backups, and restore rules are
unchanged. No provider migration is required. Already-running MCP processes
retain their loaded code until restarted normally.

## Artifacts and trust

The release retains all three CLI and two native desktop archives:

- `unpin-v1.6.0-aarch64-apple-darwin.tar.gz`
- `unpin-v1.6.0-x86_64-apple-darwin.tar.gz`
- `unpin-v1.6.0-x86_64-unknown-linux-gnu.tar.gz`
- `unpin-desktop-v1.6.0-aarch64-apple-darwin.tar.gz`
- `unpin-desktop-v1.6.0-x86_64-apple-darwin.tar.gz`

Every archive requires a CycloneDX SBOM, GitHub build-provenance and SBOM
attestations, and a `SHA256SUMS` entry. Publication also requires an approved
provider-matrix evidence bundle bound to the exact merged release commit.

macOS artifacts retain the Unpin-specific personal signing certificate,
Hardened Runtime, exact executable identifiers, and designated requirements.
Ordinary updates preserve the installed credential broker. The personal
certificate is not Developer ID signing or notarization; the maintainer-approved
unsigned-GA exception remains in effect. Follow the
[Gatekeeper and Control-click guide](../DESKTOP.md) and the
[certificate-expiry runbook](../RELEASING.md#certificate-expiry-and-rotation).

## Verification and limitations

Before publication, the exact merged release commit must pass locked Rust
checks, macOS XCTest, live Pi and OpenCode validation, and a finalized provider
matrix. Downloaded archives must pass checksum, attestation, layout, version,
architecture, signature, identifier, designated-requirement, broker, bridge,
Debian 12, and fixture-only MCP checks.

This release delivers part of the interface-design audit. Compact bulk staging
still requires returning to Rows between items. Long reviews require scrolling
without a read-to-end gate. Other visual and manual accessibility refinements,
and the native selected-tab compositor capture limitation, remain follow-up
work. Approved screenshots do not claim to resolve that capture limitation.

Provider and distribution limitations remain unchanged from
[`v1.5.2`](v1.5.2.md): Zed plugins are out of scope, Pi has no native MCP core,
and macOS archives are not Developer ID signed or notarized.
