# Unpin v0.1.0-beta.1

This is the first public beta of Unpin, a local Rust CLI/TUI for safely
inspecting and managing AI-agent configuration across Claude Code, Codex,
Cursor, Pi, OpenCode, and Zed.

## Highlights

- One normalized inventory across six providers.
- Plan-first native toggles with exact confirmation fingerprints.
- Authenticated backup manifest v3, audit evidence, rollback, and restore.
- Session → physical worktree → repository → global → native policy precedence.
- Global provider capability locks applied after profile selection.
- Persistent MCP control sessions that return human-action handoffs instead of
  approving their own writes.
- Fixture-backed validation through 31 CLI, 31 real-PTY TUI, and 31 persistent
  MCP scenarios.
- Disposable-root live-host compatibility validation for Pi 0.81.1 and
  OpenCode 1.18.4.

## Install

Download the archive for your platform:

- `aarch64-apple-darwin` for Apple Silicon macOS;
- `x86_64-apple-darwin` for Intel macOS;
- `x86_64-unknown-linux-gnu` for 64-bit GNU/Linux.

Extract the archive and place `unpin` on your `PATH`. Verify downloads against
`SHA256SUMS`. With GitHub CLI installed, verify build provenance:

```bash
gh attestation verify unpin-v0.1.0-beta.1-TARGET.tar.gz \
  --repo IgorArkhipov/unpin
```

## Safety

Start with read-only commands:

```bash
unpin providers
unpin doctor
unpin list --json
```

Persistent writes remain plan-first and require purpose-separated keychain
state, explicit confirmation, and the exact reviewed plan fingerprint.

## Beta limitations

- Windows is not supported.
- Strict live gateway attachment, native MCP-reference lifecycle, and native
  managed-hook activation remain unavailable where enforcement cannot be
  proven.
- See the attached provider-matrix evidence for the live-host and fixture
  coverage used for this release.
