# Unpin v0.1.0-beta.9

This delivery-only release hardens Unpin's artifact evidence, checksum, and
toolchain gates without changing Unpin program logic or provider behavior.

## What changed

- Corrected the pinned Rust 1.96.1 setup action and removed unsupported
  toolchain inputs so the MSRV jobs prove the intended compiler version.
- Preserved workflow-generated `SHA256SUMS` as the release trust root while
  adding provider-matrix evidence entries transactionally.
- Added no-clobber evidence uploads with scoped rollback and refused draft
  refreshes after either evidence asset exists.
- Required fresh checksum verification and an exact draft asset-name set in
  the same fail-closed block that publishes a release.
- Expanded release-tooling tests for malformed checksums, partial uploads,
  collisions, rollback, missing or extra assets, and unsafe names.

## Linux compatibility

The `x86_64-unknown-linux-gnu` archive remains built on Ubuntu 22.04 and
requires glibc 2.35 or newer. It runs on Debian 12 (glibc 2.36).

## Install

Download `unpin-v0.1.0-beta.9-x86_64-unknown-linux-gnu.tar.gz`, verify it
against `SHA256SUMS`, and verify build provenance:

```bash
gh attestation verify unpin-v0.1.0-beta.9-x86_64-unknown-linux-gnu.tar.gz \
  --repo IgorArkhipov/unpin
```

Extract the archive and place `unpin` on your `PATH`:

```bash
tar -xzf unpin-v0.1.0-beta.9-x86_64-unknown-linux-gnu.tar.gz
cd unpin-v0.1.0-beta.9-x86_64-unknown-linux-gnu
./unpin --version
./unpin --help
```

## Verification scope

This release uses the documented delivery-only artifact exception because the
changes since beta.8 are limited to release workflows, evidence tooling,
tests for that tooling, and documentation. The provider matrix and live-host
validation are therefore not rerun. Replacement evidence covers workflow lint,
locked package metadata, the beta.9 version smoke, required CI, the exact tagged
GNU/Linux artifact's `GLIBC_2.35` symbol ceiling and Debian 12 smoke, checksums,
the exact asset set, and GitHub provenance and SBOM attestations.

## Beta limitations

- Windows is not supported.
- Strict live gateway attachment, native MCP-reference lifecycle, and native
  managed-hook activation remain unavailable where enforcement cannot be
  proven.
