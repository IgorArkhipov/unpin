# Unpin v0.1.0-beta.11

`v0.1.0-beta.11` improves named-group control-plan readability in the terminal UI.

## Highlights

- Uses the consistent `Groups` title.
- Wraps and paginates long non-inventory control content.
- Shows group identities as `Agent | scope | type | name`, avoiding repeated canonical namespaces.

## Verification

- Required CI, locked metadata, the full provider matrix, and live-host validation must pass on the tagged commit.
- The release workflow verifies the GNU/Linux artifact's `GLIBC_2.35`-or-older symbol ceiling and runs `--version` and `--help` in Debian 12.
- Each archive has GitHub build provenance and a CycloneDX SBOM attestation.
- The workflow-generated `SHA256SUMS` file is the checksum trust root. Verify a downloaded archive with:

```sh
shasum -a 256 -c SHA256SUMS
gh attestation verify unpin-v0.1.0-beta.11-x86_64-unknown-linux-gnu.tar.gz \
  --repo IgorArkhipov/unpin \
  --source-ref refs/tags/v0.1.0-beta.11 \
  --signer-workflow IgorArkhipov/unpin/.github/workflows/release.yml
```

For setup and security guidance, see the [onboarding guide](https://github.com/IgorArkhipov/unpin/blob/v0.1.0-beta.11/docs/ONBOARDING.md) and the [security policy](https://github.com/IgorArkhipov/unpin/blob/v0.1.0-beta.11/SECURITY.md).
