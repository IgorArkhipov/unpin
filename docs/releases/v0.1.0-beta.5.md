# Unpin v0.1.0-beta.5

This beta hardens inventory-group execution and completes authenticated
workspace-policy maintenance across the CLI, TUI, and read-only MCP.

## Highlights

- Best-effort inventory-group apply preserves blocked members and continues
  independent cohorts while retaining per-member outcomes and recovery
  evidence.
- Fixed-source `.unpin/policy.json` migration into private workspace policy
  state with exact reviewed fingerprints and authenticated provenance.
- Explicit attached, moved, deleted, recreated, or unknown workspace
  classification before any policy reattachment or cleanup.
- Plan-first reattach, discard, cleanup, and authenticated restore workflows.
- Authenticated pre-change backups for persistent profile and capability-lock
  mutations.
- Read-only MCP workspace-policy status with exact CLI recovery handoffs.

## Compatibility

This pre-1.0 beta adds the read-only
`unpin_get_policy_maintenance_status` MCP tool and policy-maintenance JSON
contracts. Existing inventory-group definitions and approved-apply contracts
remain version-compatible with beta.4.

## Install

Download the archive for your platform:

- `aarch64-apple-darwin` for Apple Silicon macOS;
- `x86_64-apple-darwin` for Intel macOS;
- `x86_64-unknown-linux-gnu` for 64-bit GNU/Linux.

Extract the archive and place `unpin` on your `PATH`. Verify downloads against
`SHA256SUMS`. With GitHub CLI installed, verify build provenance:

```bash
gh attestation verify unpin-v0.1.0-beta.5-TARGET.tar.gz \
  --repo IgorArkhipov/unpin
```

## Safety

Start with read-only commands:

```bash
unpin providers
unpin doctor
unpin list --json
unpin group list
unpin profile policy status --json
```

Persistent writes remain plan-first and require purpose-separated keychain
state, explicit confirmation, and the exact reviewed plan fingerprint. MCP
cannot mutate workspace-policy maintenance state or approve its own group
applies.

## Beta limitations

- Windows is not supported.
- Strict live gateway attachment, native MCP-reference lifecycle, and native
  managed-hook activation remain unavailable where enforcement cannot be
  proven.
- Publication is gated on attached provider-matrix evidence for the live-host
  and fixture coverage used for this release.
