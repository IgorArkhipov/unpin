# Unpin v1.5.1

`v1.5.1` corrects false Agent Plugin warnings for current Codex plugin caches.
Schema-less Codex compatibility manifests are not portable Agent Plugins 1.0.0
packages, so Unpin no longer labels them invalid. Their native Codex activation
entries remain discoverable. The known remote-install metadata file and an
in-cache `latest` version alias also no longer make the package cache appear
incomplete. Malformed portable manifests, unexpected entries, and escaping or
broken aliases still produce diagnostics.

This is a compatible patch from `v1.5.0`. It does not change plugin activation,
provider configuration, mutation approval, backup, restore, or MCP write
authority. No provider migration is required. Already-running MCP processes
retain their loaded code until restarted normally.

## Artifacts

The release retains all three CLI and two native desktop archives:

- `unpin-v1.5.1-aarch64-apple-darwin.tar.gz`
- `unpin-v1.5.1-x86_64-apple-darwin.tar.gz`
- `unpin-v1.5.1-x86_64-unknown-linux-gnu.tar.gz`
- `unpin-desktop-v1.5.1-aarch64-apple-darwin.tar.gz`
- `unpin-desktop-v1.5.1-x86_64-apple-darwin.tar.gz`

Every archive requires a CycloneDX SBOM, GitHub build-provenance and SBOM
attestations, and a `SHA256SUMS` entry. Before publication, verify the exact
macOS signing fingerprint, executable identifiers, designated requirements,
and Hardened Runtime. The personal certificate is not Developer ID signing or
notarization; see the [Gatekeeper and Control-click guide](../DESKTOP.md) and
the [certificate-expiry runbook](../RELEASING.md#certificate-expiry-and-rotation).

## Verification

Publication requires the exact merged release commit to pass locked Rust
checks, macOS XCTest, live Pi and OpenCode validation, and a finalized provider
matrix. The draft's archives must pass checksum, attestation, layout, version,
architecture, signature, identifier, designated-requirement, broker, bridge,
Debian 12, and fixture-only MCP checks before publication.

## Known limitations

Distribution and host-verification limits are unchanged from
[`v1.5.0`](v1.5.0.md): Zed plugins remain out of scope, Pi has no native MCP
core, and the macOS desktop archives are not Developer ID signed or notarized.
