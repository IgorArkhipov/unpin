# Unpin v0.1.0-beta.7

This security-maintenance release updates the transitive `event-listener`
dependency from 5.4.1 to 5.4.2, resolving RustSec advisory RUSTSEC-2026-0221.
It does not change Unpin program logic, configuration discovery, mutation
behavior, or MCP contracts.

## Linux compatibility

The `x86_64-unknown-linux-gnu` archive remains built on Ubuntu 22.04 and
requires glibc 2.35 or newer. It runs on Debian 12 (glibc 2.36).

## Install

Download `unpin-v0.1.0-beta.7-x86_64-unknown-linux-gnu.tar.gz`, verify it
against `SHA256SUMS`, and verify build provenance:

```bash
gh attestation verify unpin-v0.1.0-beta.7-x86_64-unknown-linux-gnu.tar.gz \
  --repo IgorArkhipov/unpin
```

Extract the archive and place `unpin` on your `PATH`:

```bash
tar -xzf unpin-v0.1.0-beta.7-x86_64-unknown-linux-gnu.tar.gz
cd unpin-v0.1.0-beta.7-x86_64-unknown-linux-gnu
./unpin --version
./unpin --help
```

## Verification scope

This release changes only the locked dependency and release metadata. Focused
validation covers dependency policy, workflow syntax, locked package metadata,
a version smoke, and the exact tagged artifact's checksum, provenance,
`GLIBC_2.35` symbol ceiling, and Debian 12 / Ubuntu 22.04 runtime smoke. The
extensive provider matrix from beta.5 is not rerun because no program logic
changes.

## Beta limitations

- Windows is not supported.
- Strict live gateway attachment, native MCP-reference lifecycle, and native
  managed-hook activation remain unavailable where enforcement cannot be
  proven.
