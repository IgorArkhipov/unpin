# Unpin v0.1.0-beta.10

`v0.1.0-beta.10` is a delivery-only signed prerelease. It contains no program-logic or provider-behavior changes from the beta.9 release candidate, which remains an unpublished draft because its tag was unsigned.

## Verification

- Required CI, workflow lint, locked metadata, and the release workflow passed on the tagged commit.
- The release workflow verifies the GNU/Linux artifact's `GLIBC_2.35`-or-older symbol ceiling and runs `--version` and `--help` in Debian 12.
- Each archive has GitHub build provenance and a CycloneDX SBOM attestation.
- The workflow-generated `SHA256SUMS` file is the release checksum trust root.

Verify an archive after download:

```sh
shasum -a 256 -c SHA256SUMS
gh attestation verify unpin-v0.1.0-beta.10-x86_64-unknown-linux-gnu.tar.gz \
  --repo IgorArkhipov/unpin \
  --source-ref refs/tags/v0.1.0-beta.10 \
  --signer-workflow IgorArkhipov/unpin/.github/workflows/release.yml
```

For setup and security guidance, see the [onboarding guide](https://github.com/IgorArkhipov/unpin/blob/v0.1.0-beta.10/docs/ONBOARDING.md) and [security policy](https://github.com/IgorArkhipov/unpin/blob/v0.1.0-beta.10/SECURITY.md).
