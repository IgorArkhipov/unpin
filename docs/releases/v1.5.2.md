# Unpin v1.5.2

`v1.5.2` improves discovery under unreadable provider directories and unusual
Codex skill configuration, reduces repeated Codex TOML reads, and adds native
enable/disable for modern Zed MCP servers that declare an explicit
`context_servers.<id>.enabled` flag. Zed JSONC comments and trailing commas are
preserved. Entries without that flag continue to use the existing vault path.
Root Zed servers with a matching Stable, Preview, or Nightly override remain
read-only: changing only the root flag could misreport the effective state.
Channel-aware writes are future work.

This is a compatible patch from `v1.5.1`. Native Zed writes retain dry-run
planning, drift checks, authenticated backup, audit, and restore. No provider
migration is required. Already-running MCP processes retain their loaded code
until restarted normally.

## Artifacts

The release retains all three CLI and two native desktop archives:

- `unpin-v1.5.2-aarch64-apple-darwin.tar.gz`
- `unpin-v1.5.2-x86_64-apple-darwin.tar.gz`
- `unpin-v1.5.2-x86_64-unknown-linux-gnu.tar.gz`
- `unpin-desktop-v1.5.2-aarch64-apple-darwin.tar.gz`
- `unpin-desktop-v1.5.2-x86_64-apple-darwin.tar.gz`

Every archive requires a CycloneDX SBOM, GitHub build-provenance and SBOM
attestations, and a `SHA256SUMS` entry. Before publication, verify the exact
macOS signing fingerprint, executable identifiers, designated requirements,
and Hardened Runtime. The personal certificate is not Developer ID signing or
notarization; see the [Gatekeeper and Control-click guide](../DESKTOP.md) and
the [certificate-expiry runbook](../RELEASING.md#certificate-expiry-and-rotation).

## Verification

Publication requires the exact merged release commit to pass locked Rust
checks, macOS XCTest, live Pi and OpenCode validation, and a finalized provider
matrix. The draft's archives must pass checksum, attestation, layout, version,
architecture, signature, identifier, designated-requirement, broker, bridge,
Debian 12, and fixture-only MCP checks before publication.

## Known limitations

Distribution and host-verification limits are unchanged from
[`v1.5.1`](v1.5.1.md): Zed plugins remain out of scope, Pi has no native MCP
core, and the macOS desktop archives are not Developer ID signed or notarized.
